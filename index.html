Что это за приложение

«Горизонт» — планировщик, в котором проекты становятся созвездиями, задачи — звёздами, а зависимости — линиями между ними. Время уходит вдаль, направления расходятся в стороны, высота показывает уровень задачи. Есть и привычные списки проектов и задач и лента изменений с пояснениями.

Приложение бесплатное, без рекламы и без сбора данных. Интерфейс — на русском языке.

Частые вопросы

Где хранятся мои данные?

По умолчанию — только на вашем телефоне, без регистрации и интернета. Они попадают в резервную копию iCloud или компьютера по вашим настройкам iOS. По желанию можно подключить собственную облачную базу Supabase: тогда данные хранятся в вашем проекте и видны с любого устройства, где вы вошли. Разработчик ваших данных не видит — подробнее в политике конфиденциальности.

Как перенести данные в облачную базу?

  1. Профиль → «Экспортировать» — сохраните файл экспорта (например, в «Файлы»).
  2. Заведите бесплатный проект на supabase.com и установите в него схему «Горизонта» и создайте пользователя — пошаговая инструкция есть в приложении на экране подключения облачной базы.
  3. Профиль → «Сменить хранилище» → «В своей облачной базе», подключите базу и войдите почтой и паролем пользователя, которого создали в своём проекте Supabase (Authentication → Users → Add user).
  4. Профиль → «Импортировать» и выберите сохранённый файл. Импорт возможен только в пустое хранилище; перенесётся всё, включая ленту изменений.

Обратно — так же: экспорт из облачной базы, смена хранилища на «На этом телефоне», импорт.

Как удалить данные?

На телефоне: удалите приложение — данные удалятся вместе с ним. Если вы подключались к облачной базе, сначала выйдите из учётной записи (Профиль → «Выйти»): данные входа хранятся в Keychain iOS и иначе могут пережить удаление приложения. Адрес и публичный ключ базы там остаются — при повторной установке ими предзаполнится подключение.

В облачной базе: учётная запись удаляется в вашем проекте Supabase (Authentication → Users), данные — вместе с проектом или в редакторе таблиц.

Работает ли приложение без интернета?

С базой на телефоне — полностью. С облачной базой без сети можно смотреть последние загруженные данные; менять их — когда сеть вернётся.

About the app

Gorizont (Горизонт) is a planner that turns your projects into constellations, tasks into stars and dependencies into lines between them. Time runs into the distance, directions spread to the sides, and height shows a task's level. Familiar project and task lists and an activity feed with notes are included too.

The app is free, has no ads and collects no data. The interface is in Russian.

FAQ

Where is my data stored?

By default, only on your phone — no sign-up, no internet. It is included in iCloud or computer backups according to your iOS settings. Optionally, you can connect your own Supabase cloud database: your data is then stored in your project and available on every device where you sign in. The developer cannot see your data — see the privacy policy.

How do I move my data to a cloud database?

  1. Profile → Export — save the export file (for example, to Files).
  2. Create a free project at supabase.com and install the Gorizont schema and create a user — the app has step-by-step instructions on the cloud connection screen.
  3. Profile → Change storage → your own cloud database; connect it and sign in with the user you created in your Supabase project (Authentication → Users → Add user).
  4. Profile → Import and pick the saved file. Import works only into empty storage; everything moves over, including the activity feed.

To move back, do the same in reverse: export from the cloud, switch storage to “on this phone”, import.

How do I delete my data?

On the phone: delete the app and its data goes with it. If you have used a cloud database, sign out first (Profile → Sign out): your sign-in session is kept in the iOS Keychain and could otherwise survive deleting the app. The database address and public key stay there and prefill the connection if you reinstall.

In the cloud database: delete the account in your Supabase project (Authentication → Users), and the data together with the project or in the table editor.

Does the app work offline?

With on-phone storage — fully. With a cloud database you can view the most recently loaded data offline; changes resume when you are back online.
